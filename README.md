## О проекте

MediaPlan Optimizer строит медиаплан по восьми абстрактным рекламным инвентарям. В нём можно решить две задачи:

- Type A - есть бюджет и срок, нужно получить максимум кликов или конверсий.
- Type B - есть срок и целевой охват, клики или конверсии, нужно найти минимальный модельный бюджет.

План распределяет расходы по каналам и дням с учётом ёмкости и нелинейных кривых отклика. Если цель недостижима, сервис показывает модельный максимум, разрыв до цели и варианты изменения условий.

Данные модельные: публичные benchmark-ориентиры дополнены синтетическими предположениями, реальных рекламных API в проекте нет. Охват суммируется без дедупликации между каналами и днями - это не уникальная аудитория всей кампании.

## Онлайн-демо

[Открыть приложение](https://shad-capstone-mediaplan-optimizer.streamlit.app/) - полная публично развёрнутая версия Streamlit.

1. Нажмите «Запустить демо»: Type A, 1,2 млн руб., 21 день, максимум конверсий.
2. Посмотрите распределение бюджета по каналам и дням и сводные метрики.
3. Переключитесь на Type B: 10 000 кликов за 14 дней.
4. Проверьте недостижимую цель, например 1 трлн конверсий за один день.
5. При желании посмотрите дополнительный контур: факт → мониторинг → перепланирование → эксперименты.

Интерфейс доступен на русском и английском.

## Возможности

- 3 социальных инвентаря, Programmatic, 3 маркетплейса и SMS; воспроизводимый каталог с seed.
- Type A и Type B, включение и исключение каналов.
- Calendar-aware распределяет бюджет по парам канал-день; Uniform baseline считает дни одинаковыми.
- Бюджеты и прогноз KPI по каналам, дням и неделям.
- Охват, клики, конверсии; CTR, VTR, CR, эффективный CPM, CPC и CPA.
- Диагностика недостижимых целей и рекомендации.
- RU/EN-интерфейс, загрузка факта и экспорт таблиц в CSV.
- Дополнительно: факт кампании, мониторинг, перепланирование и исследование адаптивных стратегий в синтетической среде.

## Запуск через Docker

Из корня репозитория:

```bash
docker build -t media-plan-optimizer .
docker run --rm -p 8501:8501 media-plan-optimizer
```

Откройте <http://localhost:8501>. Сборка и локальный запуск контейнера проверены. Для остановки нажмите `Ctrl+C`.
